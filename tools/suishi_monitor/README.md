# 界園肉鴿 · 歲時與流程即時監控工具 (SuiShi Monitor)

本工具為明日方舟界園肉鴿模式 (薩米/界園相關探索流程) 的專用即時日誌監控儀表板。透過持續讀取 MAA 的除錯日誌，自動追蹤每一輪次中的**歲時抽取**、**易與商店商品**、**常樂節點**與**稀有藏品**，並在瀏覽器提供直觀的可視化介面與音效警報。

---

## 🌟 功能特點

- **歲時即時辨識與警報**：
  - 自動統計十二地支歲時出現次數與醒覺階級 (朦朧、真切、入髓、醒覺)。
  - 當刷出目標歲時 **｢辰｣ (承名：頡)** 或 **｢酉｣ (承名：方)** 時，觸發醒目的視覺高亮卡片與網頁音效提示。
- **商店商品自動清洗**：
  - 自動去除 OCR 雜訊、引號、價格、角標 (如 ｢折｣、｢OFF｣、｢NEW｣ 等)，並轉為簡體標準名。
  - 當商店刷出指定稀有藏品 (如 ｢國王的新槍｣、｢扣撓之手｣) 時進行標記與警示。
- **常樂節點與事件流水帳**：
  - 即時呈現每一步常樂事件記錄與時間軸。
- **高效多執行緒與記憶體快取**：
  - 基於 Python `ThreadingHTTPServer` 多執行緒架構，避免連線逾時卡死。
  - 根據日誌修改時間 (mtime) 與大小 (size) 進行狀態快取，API 輪詢延遲低於 30ms。

## 🚀 啟動方式

### 1. 前台直接啟動

在專案根目錄下執行：

```bash
python3 tools/suishi_monitor/server.py
```

或進入該目錄後執行：

```bash
cd tools/suishi_monitor
python3 server.py
```

啟動後終端機將顯示：

```text
==================================================
🎋 界園肉鴿 · 歲時與流程即時監控服務已啟動
🌐 本機訪問網址: http://localhost:8080
📁 監控日誌: /Users/<使用者名稱>/Library/Application Support/debug/asst.log
==================================================
```

### 2. 指定自訂連接埠或綁定位址

若 8080 埠已被佔用，可使用 `--port` 與 `--host` 參數指定：

```bash
# 指定使用 8888 埠
python3 tools/suishi_monitor/server.py --port 8888

# 僅綁定本機 localhost
python3 tools/suishi_monitor/server.py --host 127.0.0.1 --port 8080
```

### 3. 背景執行 (Daemon)

若希望關閉終端機後持續運行，可使用 `nohup` 放入背景：

```bash
nohup python3 tools/suishi_monitor/server.py --port 8080 > /dev/null 2>&1 &
```

如需停止背景程序：

```bash
pkill -f "tools/suishi_monitor/server.py"
```

## 🌐 網頁介面使用

啟動後以瀏覽器開啟：
👉 **http://localhost:8080**

- **自動刷新**：預設每 2 秒自動輪詢一次伺服器狀態。
- **聲音開關**：儀表板右上角提供 ｢聲音警報｣ 開關，刷出 ｢辰｣、｢酉｣ 或目標藏品時自動播放提醒音效。
- **包含歷史日誌**：勾選右上角 ｢包含 .bak 歷史日誌｣，可一併匯總上一輪 `asst.bak.log` 中的事件記錄。
